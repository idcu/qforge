## E-1 409 冲突：从「一次重试」升级为「可重放」

### 变更前
`js/data/api-adapter.js` 的 `writeReviews`（PUT 整表 / PATCH 增量共用）：首次 409 用 `conflictMerge(items, payload.current)` 算一次合并载荷，带 `payload.rev` 重发；**第二次 409 直接清缓存抛错**。两端同时写尚可，三端/连续写时最后一方必然失败，冲突解决变成「谁先失败谁重来」。

### 变更后
同一函数改为有界重放循环（`REVIEW_CONFLICT_REPLAYS = 3`）：

- 每轮都从**原始载荷** `body.items` 与**最新** `payload.current` 重新合并，`base_rev` 用该轮 409 返回的 `payload.rev`（不复用旧 rev、不复用上一轮合并结果）；
- 整表（PUT）走 `QB.ReviewMerge.mergeMaps`（同键 `last` 大者胜，平局保留远端）；
- 增量（PATCH）走 `conflictMerge`：只保留我方 `last` **严格更大**的键；对方更新更快时该键被收敛掉，最终载荷可为空（不覆盖对方）；
- 成功返回 `{merged: true, replays: n}`，首次即成功时不带这两个字段（与旧返回值同形）；
- 超上限或非 409 错误：清 `reviewCache` / `reviewRevCache` 后抛出，错误对象带 `replays`（仅当发生过重放）。

### 收敛性与上限
- `mergeMaps` 幂等且单调：同一对 (local, remote) 重复合并结果不变，故重放不会放大改动；
- 每轮 `base_rev` 都是服务端刚返回的最新 rev，正常情况下第 2 轮即成功；上限 3 轮只用于「持续有第三方并发写」的止损，避免请求风暴；
- 评分日志随每轮请求重发，服务端在返回 409 前不落盘（既有断言「冲突重试只追加一次评分日志」仍成立）。

### 测试证据（scripts/api-backend.test.mjs，HTTP 层注入）
- 连续两次 409 后成功：`merged=true`、`replays=2`、共 3 次 PATCH，第 2/3 次 `base_rev` 分别为 1/2；
- 重放载荷只含我方键（服务端键不回流）；
- 对方 `last` 更大时重放载荷收敛为空对象，不覆盖对方；
- 持续 409 超上限：抛 409、`replays=3`、共 4 次 PATCH、缓存被清（下次 `list` 回源）。

### A. 客户端固定动作（代码事实）
| 动作 | 请求 | 说明 |
| --- | --- | --- |
| 变更检测 | `HEAD <目录>/<固定文件名>` | 只取 `ETag` / `Last-Modified` / `Content-Length` |
| 条件上传 | `PUT` + `If-Match: <远端 ETag>` | 仅在非 force 且 HEAD 拿到 ETag 时携带 |

### C. 降级决策表（代码可保证）
| 条件 | 行为 | 后果 / 为什么这样降级 |
| --- | --- | --- |
| HEAD 返回 405 / 501 / 非 2xx / 抛错 | `{supported:false}` → 继续上传，不带 `If-Match`；上传成功 toast 追加「服务端不支持变更检测，未能确认云端是否被其他设备更新」 | 宁可让用户拿到备份，也不因服务端能力缺失而阻断；但**必须明示**检测未生效 |
| HEAD 超时（`DAV_TIMEOUT`） | 直接抛错，**不**降级为「无冲突」 | 超时无法区分「慢」与「已被改写」，静默继续等于盲覆盖 |
| HEAD 404 | 视为远端无对象，正常上传 | 首次上传路径 |
| 有 ETag 且本机无 `lastEtag` | 不判冲突（首次上传） | 没有基线就没有可比对象 |
| 有 ETag 且不一致 | `DAV_CONFLICT`，阻断上传，用户可显式「仍要上传」 | ETag 是该文件内容版本，最可靠的冲突信号 |
| 无 ETag，有 `Last-Modified` | 远端修改时间 > 本机 `lastAt + 1s` → 冲突 | 1 秒容差吸收服务端时间戳精度/时钟偏差 |
| 无 ETag 且无 `Last-Modified`，有 `Content-Length` | 大小与本机 `lastSize` 不一致 → 冲突 | 最弱判据：只能发现「变了且大小不同」，同大小改写漏检 |
| 三项都拿不到 | 不判定，直接上传 | 协议层已无可用信号；UI 仍显示「未确认」 |
| 服务端忽略 `If-Match`（不回 412） | 无冲突提示，PUT 覆盖成功 | **已知残余风险**：检测与写入之间被改写时无法发现，属服务端不支持条件请求，客户端无法弥补 |
| PUT 返回 412 | `DAV_CONFLICT`：「云端备份在检测后被其他设备更新」 | 条件请求生效，冲突被服务端拦下 |
| PUT 401/403 | 认证失败提示（检查账号/应用密码） | 与冲突区分，避免误导用户反复覆盖 |
| GET 404 | 「云端没有备份文件（先上传一次）」 | — |
| 跨域预检 / CSP `connect-src` 被拦 | fetch 失败（网络错误） | 需服务端 CORS 与页面 CSP 双向放行；纯前端无法绕过 |
