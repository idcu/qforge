# 数据存放、备份与恢复（BACKUP）

> **这份文件是什么**：`user-guide.md` 原 §9 —— 数据存在哪、怎么导出、怎么跨设备迁移、
> 存储升级时会发生什么、空间不足怎么办。
> **为什么单独成文**：它是**出事时才翻**的一节（备份/恢复/空间不足），与"怎么刷题"不是同一场景；
> 放在 user-guide 里让那份文档 32KB、每次改功能都要读一遍。
> **也适用于**：换浏览器、清缓存前、迁移到新设备、点了"回退到 LocalStorage"。

数据保存在浏览器本地：**默认使用 IndexedDB**（容量上限由浏览器按站点分配，远大于 LocalStorage 的约 5MB），LocalStorage 只保留极小的版本/迁移状态。若浏览器禁用 IndexedDB（如部分隐私模式）或配额被拒绝，应用会**自动回落到 LocalStorage** 并继续可用，此时仍受约 5MB 限制。首页「本地存储」卡片实时显示占用量与进度：≥70% 变橙提示适时备份，≥85% 变红提示尽快导出。清理浏览器数据会清空题库与学习记录，请及时用「导出」备份。

> **首次启动的存储迁移**：从旧版本升级时，应用会**分批**把 LocalStorage 里的数据搬到 IndexedDB（按 200 题/片流式复制、逐批校验），状态栏会显示「正在迁移存储到 IndexedDB X%（done/total）」；中途关闭页面也不丢进度，**下次启动从断点继续**，不会从头重跑。迁移完成当次会**保留旧 LocalStorage 数据作为退路**；**下一次启动**校验 IndexedDB 数据完整后**自动清理**旧 LocalStorage（只保留极小的启动标记）。清理失败不会损坏任何一侧，下次启动可重试。可在「备份与恢复」弹窗查看迁移状态，或手动「清理旧 LocalStorage」「回退到 LocalStorage」（回退会先校验空间，失败则保持 IndexedDB、不会半切）。

### 打印 / 另存 PDF

答题列表、题目、成绩页支持浏览器直接打印（Ctrl/Cmd+P）：打印样式会自动隐藏顶栏、标签栏、按钮与弹窗，只保留主体内容，可用于纸质练习或存档。

### 全量备份与恢复（跨设备迁移）

首页「备份与恢复」可把**全部数据**（题库、题目、错题、收藏、SRS 复习计划、历史、偏好）打包成一个 `qforge-backup-日期.json`：

- **下载全量备份**：得到单文件，建议定期保存；换设备/换浏览器时用它迁移。无图为 `.json`，含图片自动打包为 `.qfbk`（ZIP）。**WebDAV 密码不写入备份**（地址/账号保留，恢复后重新填密码），备份文件可安全分享。
- **从备份恢复**：选择备份文件（.json/.qfbk 自动识别），可选「覆盖恢复」（清空现有数据与图片后写入，推荐）或「合并恢复」（同名逻辑键覆盖；备份未包含的键与图片保留。注意：`banks/history/revlog` 若在备份中会整体替换，不是按 id 合并）。恢复后刷新页面。**备份载荷会自动适配当前后端**：本机是本地模式而备份来自 `DATA_BACKEND=api` 的后端（或反过来）时，题目/进度/历史等会按当前后端口径自动转换后落库，无需手工处理；后端布局不含本机专有偏好（主题/当前库/WebDAV 配置/schema 版本），覆盖恢复时会**保留本机现值**而不是清空。
- **☁ WebDAV 云备份**：配置 WebDAV 目录（坚果云/Nextcloud/群晖等）后一键 PUT 上传全量备份、GET 拉取并走同一恢复确认；固定对象名 `qforge-backup-latest.bin`，账号密码仅存本机 LocalStorage，**上传的备份包已脱敏密码**（换机恢复后需重填）。**CORS 限制**：浏览器要求 WebDAV 服务允许本站跨域，坚果云等公共服务默认可能被拦截（报错属浏览器/服务端策略），自建服务通常可配置。**自测真机**：仓库自带本地验证端点 `node scripts/serve-webdav.mjs`（127.0.0.1:8899，账号/密码 `u`/`p`，已开 CORS，仅用于验证 WebDAV 链路；见 [DEVELOPMENT.md](DEVELOPMENT.md) §1）。
- 弹窗显示当前后端（IndexedDB / LocalStorage）与本地存储占用；LocalStorage 模式超过约 4MB 会提示尽快备份、分库（图片在 IndexedDB 不占用该配额）。迁移后旧 LocalStorage 空间会**在下次启动校验通过后自动回收**（也可手动点「清理旧 LocalStorage」）。

> WebDAV 是手动触发的异步备份，不是实时多端同步；真正的账号化实时同步走 `DATA_BACKEND=api` 后端契约（见 §1.1 与 [DATABASE.md](DATABASE.md)、[API-CONTRACT.md](API-CONTRACT.md)）。

### 存储升级与空间不足提示

旧版本数据首次在新版打开时，应用会**在后台**把 LocalStorage 升级到 IndexedDB（schema v6），状态栏显示「正在迁移存储到 IndexedDB X%」，期间可以正常使用。

- **升级不再向 LocalStorage 追加业务数据**：迁移期间只写锁/进度/标记等引导键，复习状态、评分日志等全部直接进目标后端（IndexedDB）。因此**旧库即使接近 LocalStorage 上限也能完成升级**（真机实测 12k 题库占探测预算 4.85M/5.19M 字符、93% 时成功）。
- **接近上限（≥85%）**：升级成功后提示「本地存储已接近上限（已用约 X%），本次存储升级已完成；建议在「备份与恢复」导出备份并清理空间」。提示不影响使用；迁移完成后的下次启动会在校验通过后自动回收旧 LocalStorage 空间。
- **IndexedDB 不可用（隐私模式/被浏览器策略禁用等）**：升级只能把数据复制进 LocalStorage。若空间不足，应用会**在写入任何数据之前**中止并提示：
  「存储升级已跳过：IndexedDB 不可用，且 LocalStorage 空间不足以在本机完成升级（已用 X / 上限 Y 字符）。现有数据未改动。」
  此时继续以兼容模式使用；请先导出备份、清理空间后刷新重试。
- **失败不会半写**：任何升级失败都会保留改动前的数据（LocalStorage 未被改写，或按快照回滚），不会出现「迁移到一半、新旧两份都不完整」。
- **预检是运行时探测，不再用固定阈值**：应用会在首屏渲染后的空闲期（`requestIdleCallback`，无则 800ms 兜底）用独立探测键实测当前浏览器/设备可写的 LocalStorage 字符上限，分辨率 16Ki 字符，**探测后立即删除探测键**；结果缓存 7 天（回退值 1 小时），浏览器 UA 变化或缓存失效时自动重测。预检按探测值判定，换 Safari / Firefox / 移动端不再套用 Chromium 的硬编码值。若探测失败（写入被拒、单键超限、未知异常等），自动回退保守常量 **5,210,112 字符**，并在状态里标明「来源=保守常量」，**不会把回退值冒充成探测值**。容量仍按序列化**字符数**计（不是字节）；极少数环境可能出现「实际还能装下但提示空间不足」——这是刻意选择的安全方向（宁可提前提示，不在中途爆配额）。
