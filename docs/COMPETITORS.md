# 竞品全维度对比与定位（COMPETITORS）

> 目的：在**题库/刷题/间隔重复**赛道上，把淬题（qforge）与主流产品放在同一组维度下比较，明确差异化定位与真实差距。
> 核实日期：**2026-10-14**，信息来自各产品官网/帮助中心与公开评测（来源见 §5）。商业产品功能与价格会变动，引用时以官网现状为准；qforge 列的每一项均与当前代码一一对应，不写路线图当已实现。

## 1. 竞品画像（四类典型形态）

| 产品 | 形态 | 一句话画像 |
| --- | --- | --- |
| **Anki**（AnkiWeb / AnkiDroid / AnkiMobile） | 开源桌面 + 多端 | 间隔重复事实标准：卡片模板 + SM-2/FSRS 调度 + 插件生态；桌面/安卓免费，iOS 收费 |

## 3. qforge 的差异化定位

1. **格式主权 + 零信任迁移**：导入解析与导出全部在本机完成，且 6 种格式可往返、有真实夹具回归。对「题库在平台手里、导出无门」的 SaaS 是直接对立面——适合自有版权题库、培训机构内网、敏感考试场景。
2. **唯一把「考试系统题型」与「FSRS 记忆科学」做进同一个零依赖静态包的产品**：Anki 强在记忆曲线但没有判分/组卷/考试；考试宝强在组卷考试但算法黑箱、数据在云端。qforge 在交集上：不定项少选半分还会作为 hard 信号回流 FSRS（见 [SRS.md](SRS.md) §3）。
3. **可审计、可自托管、可演进**：无构建无混淆，前后端只隔一层 Repository 契约；涉密环境能整包放内网静态服务器，后续接后端不用重写 UI。
4. **成本为零、无账号、无配额**：对比 Quizlet 的订阅墙（Q-Chat/练习测试/离线均在 Plus 后）、考试宝企业套餐，qforge 全功能免费且功能不随会员策略变化。
