# 使用指南（user-guide）

> 面向使用者的操作说明。功能行为变更时须同步更新本文档。

## 1. 打开与启动

- **直接打开**：双击 `index.html`（纯前端，无需安装）。
- **本地服务（推荐）**：`node scripts/serve.mjs` → 浏览器访问 `http://localhost:8777`。

首次进入是空系统，需要导入或新建题库。

## 2. 题库管理

顶部下拉框可切换当前题库；点击「管理题库」进入题库列表。

| 操作 | 说明 |
| --- | --- |
| 新建题库 | 输入名称（可选描述/分类）创建 |
| 重命名 | 修改题库名称 |
| 删除题库 | **级联删除**该库下所有题目、错题、收藏、历史 |
| 切换当前题库 | 顶部下拉选择；题目与学习数据按库隔离 |
| 导入示例题库 | 一键载入内置 15 题样例（5 题型各 3 题） |

## 3. 导入题库

点击「导入」选择文件，支持：

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| JSON | `.json` | 标准数组 / 本系统导出格式 / 中文扁平 / 中文嵌套（自动嗅探） |
| CSV / TSV | `.csv` `.tsv` `.txt` | 表头映射（题目/题型/选项A–D/答案/解析…，中英兼容） |
| Markdown | `.md` `.markdown` | 按 `## 1. 题干 / - **A.** 选项 / **答案：X**` 排版；与本系统 md 导出互通，可往返 |
| Excel | `.xlsx` | 读取第一个工作表，按表头映射，原生解析 |
| Word | `.docx` | 按「1. 题干 / A. 选项 / 答案：X」排版切题 |

导入流程：**选择文件 → 预览（题量/各题型/警告/重复）→ 选目标题库 → 合并或覆盖 → 落库**。

- **合并**：保留库内已有题目，仅新增不重复的题。
- **覆盖**：清空目标题库后写入（谨慎使用）。
- 去重键为「题型 + 规范化题干」，重复题自动跳过。
- 详细格式规范见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md)。

导出：题库列表点击「导出」（或错题本「导出错题」），弹窗选择 JSON / CSV / Markdown / TXT 格式，详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。

### 3.1 题目管理（新增 / 编辑 / 删除）

首页「题目管理（新增/编辑/删除）」打开题库内管理器：

- 顶部可按**题型**和**题干关键词**筛选，每页 10 题分页浏览；行内显示题型、难度（★）、分类/标签与答案预览。
- **＋ 新增题目**：选择题型后填写题干、选项（勾选左侧即正确项，可增删选项、字母自动重排）或填空空位/简答参考答案，并设置解析、分类、难度（1–5）、标签。保存前会校验题干、选项数与正确答案。
- **编辑**：修改后保存；编辑难度/标签/分类不影响去重键（错题、收藏不会因此丢失关联）。
- **删除**：单题删除需确认；勾选多题后可「删除所选项」批量删除。操作不可恢复。

## 4. 刷题模式

| 模式 | 说明 |
| --- | --- |
| 练习模式 | 每题作答后即时判分；简答题作答后可**自评**对/错 |
| 考试模式 | 计时（默认 30 分钟）、交卷后**整卷判分**；简答题按未得分计 |
| 组卷（混合出题） | 按**每题型数量**抽题，可用分类、难度区间（1–5）过滤；题量不足按实际数量组卷并提示；可选择练习或考试模式 |
| 错题练习 | 从错题本抽取重新练习 |
| 收藏练习 | 从收藏夹抽取练习 |
| 今日复习 | **间隔重复（SRS）**：自动汇总今日到期与未学过的题，答完按对/错安排下次复习时间 |

**间隔重复（今日复习）**：系统对每道题维护复习节奏（参考 SM-2）：答对会把下次复习间隔按 1 天 → 3 天 → 约 7 天…逐步拉长，答错则重置为当天再复习。首页「🧠 今日复习」显示今日到期题数（带红点），进度按题库分别保存在本地。

**判分规则**：判断题（对/错）、单选（字母）、多选（集合相等）、**不定项**（答案可能 1～多个：全对满分，少选且未选错得半分，错选/多选 0 分，且不进错题本）、填空（逐空比对，忽略大小写/空格/全角）；简答题不自动判分，练习时由用户自评。

**选项乱序**：练习与考试时，单选/多选题的选项会**随机排列**，正确答案字母随之自动调整，避免背位置。该乱序只影响当次作答（题库里存储的原始顺序不变），可在 `js/config.js` 的 `SHUFFLE_OPTIONS` 关闭；判断题（固定 正确/错误）、填空、简答不参与。

## 4.1 导出数据

| 入口 | 导出对象 | 说明 |
| --- | --- | --- |
| 题库管理 → 导出 | 整个题库 | 导出当前题库全部题目 |
| 错题本 → 导出错题 | 错题本 | 仅导出错题，附错误次数 |

点击后弹窗选择格式：

- **JSON**：标准备份结构，可再次导入（推荐用于迁移/备份）。
- **CSV**：Excel 可直接打开（带 UTF-8 BOM 不乱码），也可再次导入。
- **Markdown**：含答案解析的题单，便于阅读/打印，也可再次导入（往返）。
- **纯文本 TXT**：等宽排版试卷。

文件名形如 `物业题库A-错题本-36题-20261013-1830.csv`。收藏夹导出的内部能力已就绪（预留），历史记录导出待后续版本。详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。

## 5. 学习数据

- **错题本**：答错的题自动进入；可单独移除或清空；支持一键错题练习。
- **收藏夹**：答题页点「收藏」加入；可移除或清空；支持收藏练习。
- **历史**：每次练习/考试记录得分、正确率、用时；可删除单条或清空。
- **统计**：总览（测试次数/答题数/平均正确率）、各题型掌握度、学习建议。
- **搜索**：按关键词检索（命中高亮）、按题型/分类筛选，可直接从结果开始练习。

## 6. 键盘快捷键（答题页）

| 按键 | 作用 |
| --- | --- |
| `1` – `8` | 选择对应序号的选项 |
| `Enter` | 提交当前题 / 未作答时进入下一题 / 末题结束 |
| `←` / `→` | 上一题 / 下一题 |
| `Esc` | 关闭弹窗 |

> 在有输入框/文本域/下拉框获得焦点时，快捷键自动让位（不干扰输入）。

## 7. 进度恢复

练习/考试过程中每答一题都会自动保存进度。刷新或重开页面后，会提示是否**继续上次未完成的答题**。

## 8. 外观

右上角按钮在**浅色 / 深色**主题间切换，偏好会记住。

## 9. 数据存放

数据保存在浏览器本地（LocalStorage，前缀 `qb:`）。清理浏览器数据会清空题库与学习记录，请及时用「导出」备份。

### 9.1 全量备份与恢复（跨设备迁移）

首页「备份与恢复」可把**全部数据**（题库、题目、错题、收藏、SRS 复习计划、历史、偏好）打包成一个 `qforge-backup-日期.json`：

- **下载全量备份**：得到单文件，建议定期保存；换设备/换浏览器时用它迁移。
- **从备份恢复**：选择备份文件，可选「覆盖恢复」（清空现有数据后写入，推荐）或「合并恢复」（同名键覆盖、保留其余数据）。恢复后刷新页面。
- 弹窗显示本地存储占用，超过约 4MB 会提示尽快备份、分库。

> 后续版本将支持后端与数据库，实现跨设备同步（见 [DATABASE.md](DATABASE.md) 与 [API-CONTRACT.md](API-CONTRACT.md)）。

## 10. 已知限制

- `.xlsx` / `.docx` 解析依赖浏览器 `DecompressionStream`；过老浏览器可能不支持。
- LocalStorage 容量有限（通常 5–10MB），超大题库建议分库或迁往后端。
- 应用支持 **PWA**：通过 https 访问（如 GitHub Pages）时可用浏览器「安装到主屏幕/桌面」，Service Worker 缓存后可离线打开；`file://` 双击场景不启用离线缓存。
