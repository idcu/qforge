# 使用指南（user-guide）

> 面向使用者的操作说明。功能行为变更时须同步更新本文档。

## 1. 打开与启动

- **直接打开**：双击 `index.html`（纯前端，无需安装）。
- **本地服务（推荐）**：`node scripts/serve.mjs` → 浏览器访问 `http://localhost:8777`。

首次进入是空系统，需要导入或新建题库。

- **启动失败时**：页面不会白屏，`#view` 会显示「启动失败」错误态，状态栏同步提示错误信息；可刷新重试。若反复失败，点「下载诊断信息」导出 JSON（仅含错误栈、启动状态与存储模式，不含题目内容/密码/备份数据）用于反馈。本地数据不会被本次失败的启动修改。

### 1.1 自建后端（可选，多设备/团队）

默认数据存本机浏览器（`localStorage` + IndexedDB）。若想让数据落在自己的服务器、供多设备共享，可启用随仓库附带的**零依赖参考后端**：

```bash
# 静态文件 + /api/* 一并提供（默认 127.0.0.1:8788，数据写入 .qforge-data/）
node scripts/serve-api.mjs
# 浏览器打开：http://127.0.0.1:8788/?backend=api
```

- 后端实现见 [API-CONTRACT.md](API-CONTRACT.md)（数据落工程根 `.qforge-data/` 的 JSON，已 gitignore；原子写入）。
- **切换后端不改动任何前端代码/界面**——SRS 复习计划、备份、图片资产等都已纳入数据层契约（见 [ARCHITECTURE.md](ARCHITECTURE.md) §3.3 与 [SRS.md](SRS.md) §9）。作答热路径已收敛：调度状态与评分日志合并为一次 `PUT /api/banks/{id}/reviews`，权重与复习表按库缓存，连续作答通常只剩 1 个写请求；多端同时作答时按每库版本号（`rev`）+ 题状态 `last` 自动合并：服务端以 409 拒绝过期写入并返回当前表，客户端保留每道题 `last` 更新的一方后重试一次，评分日志不重复提交。并发权重/日志的实时合并仍未实现（单用户参考实现口径）。
- 页面默认启用 **CSP**（`script-src 'self'`，禁止内联脚本/eval；本地服务另加 `X-Frame-Options: DENY`、`nosniff`、`Referrer-Policy`）。二次开发若新增内联 `<script>` 或 `eval` 会被浏览器拦截，请放外部 `.js` 文件；**C020 起 `connect-src` 默认仅 `'self'`**——自建后端、WebDAV 或 URL 导入若在**非同源**地址，浏览器会直接拦截，必须按 [DEVELOPMENT.md](DEVELOPMENT.md) §配置把该 origin 显式加入 `NETWORK.CSP_CONNECT_ALLOWLIST`、`index.html` meta 与 `security-headers.mjs` 的 CSP（两处逐字符一致）；同源部署（如 `'/api'`）无需放行。`file:` 仅用于双击 `index.html` 直开时的本地资源加载，网络出口不放行 `file:`。WebDAV 设置弹窗中的密码只经 DOM `value` 回填，**不写入 HTML 属性/源码**（R-14）；这不能防同源 XSS，建议使用应用专用密码。
- 说明与已知限制：参考后端**单用户**；`/api/*` 默认无鉴权，设置 `API_TOKEN` 后服务端要求 `Authorization: Bearer <token>`（前端在 `config.js` 的 `NETWORK.API_TOKEN` 填同一值即自动附带；静态文件与 `/health` 不受保护），**共享密钥不是账号体系**，对公网暴露前必须启用令牌；同源公开部署时令牌在**前端包内可见**，只能作最低限度访问控制，不能替代账号权限；参考后端默认 **1200 次/分钟/IP 限流**（`RATE_LIMIT_MAX`/`RATE_LIMIT_WINDOW_MS` 可调、`RATE_LIMIT_MAX=0` 关闭；反向代理后需 `TRUST_PROXY=1` 才按 `X-Forwarded-For` 分桶），超限返回 429；**题目编辑已启用 `updated_at` 乐观并发**（两台设备同时改同一题时，后提交者收到 409「题目已在其他设备修改」，不会静默覆盖）；**复习计划已启用每库 `rev` 乐观并发**（过期写入返回 409，客户端按各题 `last` 合并后自动重试一次，评分日志只提交一次），并发权重/日志的实时合并仍未实现；后端不可用时界面会如实报网络错误（不静默返回假数据）。

## 3. 导入题库

点击「导入」选择文件，支持：

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| 题库包 | `.qbk` | stored ZIP（bank.json + `assets/*`），**唯一携带图片**的导入格式，见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md) §9 |
| JSON | `.json` | 标准数组 / 本系统导出格式 / 中文扁平 / 中文嵌套（自动嗅探） |
| CSV / TSV | `.csv` `.tsv` `.txt` | 表头映射（题目/题型/选项A–D/答案/解析…，中英兼容） |
| Markdown | `.md` `.markdown` | 按 `## 1. 题干 / - **A.** 选项 / **答案：X**` 排版；与本系统 md 导出互通，可往返 |
| Excel | `.xlsx` | 读取**全部工作表**（首行表头，空表跳过，多表合并），按表头映射，原生解析 |
| Word | `.docx` | 按「1. 题干 / A. 选项 / 答案：X」排版切题；**支持内嵌图片**（DrawingML/VML 自动提取到 IndexedDB，见 3.3） |
| Anki | `.apkg` | 仅支持 Anki「**兼容旧版 / Legacy**」导出（Legacy1/2）；按 note 导入，Front→题干、Back→参考答案；图片自动入库；`.anki21b`（最新格式）会明确提示不支持并指引导出旧版 |
| Quizlet | `.txt` `.quizlet` | 每行 `term<Tab/逗号/分号/竖线>definition`，自动识别分隔符；全部落为简答（term 题干 + definition 参考答案），无选项/图片/在线进度 |

导入流程：**选择文件 → 预览（题量/各题型/警告/重复）→ 选目标题库 → 合并或覆盖 → 落库**。JSON/.qbk 若带内容校验和（本系统导出默认带），预览会显示「一致 / 不一致」；不一致会同时给出警告，但**不阻断导入**（由你决定是否继续）。

- **材料题（综合题）导入**：JSON/.qbk 直接支持；Markdown/Word 用行式材料块（`[材料题]` 引导行 + `材料：` + `(1). [题型]` 小问，见导入格式说明 §6.1/§5.2）；CSV/Excel 用「材料/小问」两列多行块（表头含材料题时导出自动追加两列，有小问分值时再追加「小问分值」列，见 §3.1）。各格式导出 → 再导入均可往返题目内容；**小问分值在 MD/DOCX/CSV/XLSX/JSON 中均保留**（行式与表格格式使用 `分值：N` / 第 19 列）。

- **合并**：保留库内已有题目，仅新增不重复的题。
- **覆盖**：清空目标题库后写入（谨慎使用）。
- **材料题少于 2 个小问会被整包拒绝**：材料题必须是「共享材料 + 至少 2 个小问」。若导入文件里出现只有 1 个小问的材料题，导入会在预览前停止，弹窗写明「至少 2 个」并说明**未写入任何题目**（同一文件里的其他正常题也不会落库）；请把该题改成普通题，或补足小问后重新导入。题目管理器的材料题编辑器同样要求至少 2 个小问。
- **导入要么全成、要么全不成**：落库前先做容量预检，空间不足会直接提示「本次约需 / 当前可用 / 已用 / 上限」且**不写入任何数据**；写入中途失败（配额耗尽/磁盘错误）会自动回滚到导入前状态，提示「写入失败（已回滚到导入前状态）：原因」。只有确认已落盘且回读题数一致才提示「导入完成」。
- **文件体积先判后读**：本地文件单文件上限 **16 MiB**（`CONFIG.LIMITS.IMPORT_MAX_BYTES`，初值）；超过时在读取/解析之前就提示「超过导入上限 / 未读取文件、未写入任何题目」，不会把整文件读入内存，也不会打开预览。网络地址导入仍是 **8 MiB** 上限，两者以更严格者为准；超大包请拆分或压缩后重试。
- **批注总量超限会被拒绝**：单库批注总量上限为 **2 MiB**（UTF-8 字节，`CONFIG.LIMITS.ANNOTATION_TOTAL_MAX_BYTES`）。导入题包若自带批注超限，会在预览前停止并弹窗写明当前字节/上限/超出量，处理方式是**删减批注后重试**或**导入不含批注的版本**；本次不会写入任何题目（合并模式下还会算上目标库已有批注）。保存单题批注同样会预检，超限时错误框给出同样信息，**本次保存不落库**——不会静默截断批注。
- 去重键为「题型 + 规范化题干 + 选项 + 正确答案」：题干相同但选项或答案不同的题会分别保留；分类/难度/标签差异不视为不同题。重复题自动跳过。
- **粘贴文本导入**：首页「粘贴文本导入」直接粘贴 JSON（标准结构/数组）、Quizlet 的 term/definition 两列文本（Tab / 逗号 / 分号分隔均可，全落简答、无选项/图片/在线进度），或行式题目（`1. 题干 / A. 选项 / 答案：X / 解析：… / 分类：… / 难度：… / 标签：…`）。粘贴与文件/拖拽/URL 走同一解析路径，无需先存成文件。若解析出 0 题，弹窗会**停留并以红色错误框展示具体原因**（例如 Anki `.anki21b` 会提示勾选「兼容旧版 / Legacy」），而不是只提示「未解析出任何题目」。
- **解析类字段自动合并**：外部题库把「解析 / 解题思路 / 考点 / 释义」拆成多列（JSON/CSV/XLSX）或多种标记行（Markdown/DOCX/粘贴）时，导入统一并入题目的「解析」：JSON/CSV/XLSX 按「解析 → 解题思路 → 考点 → 释义」顺序、行式按文中出现顺序，以 `【标签】` 分段；仅解析一类时保持原样。导出仍为单列「解析」，内容不丢，但不还原原表多列结构。
- **Anki / Quizlet 迁移**：
  - Anki：在 Anki 桌面端「导出 → Anki 卡组包（.apkg）」时勾选「**兼容旧版 / Legacy**」（新版默认的 `.anki21b` 本系统不支持，会直接提示并拒绝，不会假装导入）。导入按 **note** 合并，同一张卡片的多个模板（如「正面→背面」「背面→正面」）只生成 1 题，**独立复习历史与 cloze 多空位多卡语义无法保留**，预览会明确列出丢失数量；源 revlog（复习记录）不导入，迁移后按新题开始学习。Front/Back 会自动去 HTML 并尽量判成单选/判断，其余落简答；Back 作为参考答案；缺失图片保留「[图片缺失：xxx]」占位并警告。
  - Quizlet：在 Quizlet 里复制/导出为「Term + Definition」两列文本（Tab、逗号或分号分隔均可），存成 `.txt` 直接导入；全部落为简答，**没有选项、图片和在线学习进度**。含「题目/答案」等表头的普通 CSV 仍按 CSV 处理，不会被误当 Quizlet。
  - 两种迁移都只搬运题目内容，不模拟原平台的排程/游戏化功能；详见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md) §11。
- **网络地址导入**：在 http(s) 环境（GitHub Pages / 本地服务；`file://` 双击时禁用）点「网络地址导入」，粘贴 json/csv/tsv/txt/md/markdown/xlsx/docx/qbk/**apkg** 的直链，拉取上限 8MB、15 秒超时。远端文件以**快照**保存到本地，可离线、可备份；题库卡片显示 🌐 来源，可用「↻ 刷新网络来源」重新拉取，内容指纹（checksum）未变会提示无更新，有变化则去重合并。服务器必须允许跨域（CORS），否则请另存为文件后拖拽导入；需要登录的私有地址不支持，请走未来的 REST 后端。
- 题库卡片显示**来源徽章**：📁 本地创建 / 📄 文件 / 📋 粘贴 / 🖱️ 拖拽 / 🌐 网络。
- 详细格式规范见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md)。

导出：题库列表点击「导出」（或错题本「导出错题」、收藏夹「导出收藏」），弹窗选择 JSON / CSV / Excel(.xlsx) / Word(.docx) / Markdown / TXT / **只读分享页(.html)** 等格式；除 TXT 与 HTML 外均可再次导入往返。**分享页是单个自包含 HTML 文件**（含题目/选项/答案/解析，图片内嵌），可直接发给别人用浏览器打开，无脚本、无网络请求，详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。
**批注总量超过上限时，导出前会先询问**：当前单库批注超过 **2 MiB** 时，选择会被明确二选一——「**不含批注继续导出**」（题目/答案/解析/图片照常导出，仅省略批注，**本机批注数据不变**）或「**取消**」（不导出，回到题库删减批注后重试）。JSON/.qbk/分享页会携带批注，CSV/Excel/Word/Markdown/TXT 本来就不含批注，因此不触发该提示；任何情况下都不会静默截断批注。

### 3.1 题目管理（新增 / 编辑 / 删除）

首页「题目管理（新增/编辑/删除）」打开题库内管理器：

- **新建材料题（M3）**：工具栏「＋ 新建材料题」打开专用编辑器——填写共享材料（或总题干/引导语），下方逐个小问卡片可选题型（判断/单选/多选/不定项/填空/简答）、编辑选项与正确答案、填空答案、参考答案与解析、**小问分值（1–100，默认 10）**；支持「＋ 添加小问」「删除小问」；至少 2 个小问，父题分类/难度/标签/解析统一管理。已导入的材料题点「编辑」也进入该编辑器。
- 顶部可按**题型、难度、标签、题干关键词**组合筛选（标签候选项来自当前题库），每页 10 题分页浏览；行内显示题型、难度（★）、分类/标签与答案预览。
- **＋ 新增题目**：选择题型后填写题干、选项（勾选左侧即正确项，可增删选项、字母自动重排）或填空空位/简答参考答案，并设置解析、分类、难度（1–5）、标签。保存前会校验题干、选项数与正确答案。
- **编辑**：修改后保存；编辑难度/标签/分类不影响去重键（错题、收藏不会因此丢失关联）；修改题干/选项/答案会生成新的内容键（等同新题，旧作答记录不迁移）。
- **批注（本地）**：编辑/新增题目时可写「批注」（最长 5000 字，支持换行；材料题写在父题）。批注只保存在本机，**不参与去重键**，写批注不会让错题/收藏/复习记录失去关联。导出 JSON/`.qbk` 时批注随题带走，复制/分发后对方导入即可看到；练习反馈、材料题总评与只读分享页都会展示批注。CSV/Excel/Word/Markdown/TXT 不含批注列。**自建后端（api）模式暂不支持批注**（编辑器会禁用并说明原因）。
- **删除**：单题删除需确认；勾选多题后可「删除所选项」批量删除。操作不可恢复。

### 3.2 题干中的轻量公式（上下标 / 分式 / 根号）

题干、选项、解析、参考答案均支持纯文本公式记号（各导入/导出格式原样保留，无需转义）：

| 写法 | 显示 | 示例 |
| --- | --- | --- |
| `x^{2}` | x<sup>2</sup> | `E=mc^{2}`、`10^{3}` |
| `a_{n}` | a<sub>n</sub> | `H_{2}O`、`a_{n+1}` |
| `\frac{a}{b}` | a/b 上下两行带分数线 | `v=\frac{s}{t}` |
| `\sqrt{x}` | √x（带根号上划线） | `\sqrt{2}` |
| `\sqrt[n]{x}` | n 次根号 | `\sqrt[3]{8}` |

- 花括号必须成对出现；普通文本里的 `^`、`_`、`\`（如 `snake_case`、`2^3`、路径 `C:\temp`）不受影响、原样显示。
- 分式/根号的参数组支持**嵌套**，且内部可继续使用上下标与公式：如 `\frac{x^{2}}{y_{1}}`、`\sqrt{\frac{a}{b}}`、`\frac{-b+\sqrt{b^{2}-4ac}}{2a}`；参数组未闭合时原样显示。
- 希腊字母等 Unicode 符号（α、β、π、℃、≥）直接输入即可，无需特殊语法。
- 按零依赖定位只做上述**子集**（CSS 排版，不引入 KaTeX/MathJax）；矩阵、求和号、字体/空格指令等完整 LaTeX 不在支持范围内。搜索/列表标题使用去记号后的纯文本（`\frac{a}{b}`→`a/b`、`\sqrt{x}`→`√(x)`）。

### 3.3 图片题（IndexedDB 本地存图）

题干、选项、解析、参考答案均可插图，图片二进制不占用 localStorage 配额：

- 在编辑器先点击目标文本框（题干/选项/解析）定位光标，点「**📷 插入图片**」选本地图片，保存题目即可；标记语法为 `![](asset:图片id)`，随文本保存。
- JPEG 超过 1600px 长边时自动按 0.82 质量压缩；PNG/GIF/WebP/SVG 原样保存以保留透明与动画。
- 图片存在浏览器 **IndexedDB**（按内容哈希去重，同图不重复占空间）；**file:// 双击打开时 IndexedDB 在部分浏览器被禁用**，图片题请通过 `node scripts/serve.mjs` 或 GitHub Pages 使用。
- **DOCX 导入支持内嵌图片**：Word 文档中题干/选项/解析段落里的图片（DrawingML `a:blip`，兼容旧版 VML）会随切题自动提取——图片字节写入 IndexedDB，题面相应位置插入占位标记；重复导入同图按内容哈希去重；文档引用了但包内缺失的图片会在预览中警告并跳过，不影响切题。图片归属按段落就近挂接（独立图片段落续接到题干），复杂文本框/嵌套表格排版可能错位，导入后请预览核对。
- 带图题库的跨设备迁移必须导出「**题库包 .qbk**」（导出端只有 .qbk 携带图片字节；JSON/CSV/XLSX/DOCX/MD 导出仅保留占位文本，但 **DOCX 文件导入时可以带图**）；.qbk 可再次导入并自动回写图片，缺图会在预览警告。**材料题**（共享材料正文与各小问）中的图片同样随 .qbk/.qfbk 携带（2026-10-19 修复：此前引用集只扫题干/选项/解析，漏扫材料正文与小问）。
- 「备份与恢复」在存在图片时自动导出 `.qfbk` 包（数据 + 全部图片），无图时仍是单个 JSON；备份管理中可「清理未引用图片」回收空间（删题后残留的图）。
- 图片占位在做题、解析回顾处自动加载；列表/搜索以 `[图]` 紧凑显示。

## 4. 刷题模式

| 模式 | 说明 |
| --- | --- |
| 练习模式 | 点击后弹窗按题型设置**抽取数量（0=不选该题型）与每题分值（留空=按题目自带分值/默认 10）**，并可选分类、单独开关本场「选项乱序」「材料题小问乱序」与「显示计时（正计时，默认关闭）」；**自动回填上次使用的数量/分值/分类/时长与开关**（存本机 `meta:startPrefs`，不随题库同步）；无题库或题池为空时提示、不打开空弹窗；每题作答后即时判分；简答题作答后可**自评**对/错；分值仅本场生效，不写回题库 |
| 考试模式 | 点击后弹窗同样按题型设置**抽取数量与每题分值**，并可设**考试时长（分钟，默认 30，0=不限时）**、开关本场「选项乱序」「材料题小问乱序」；时长>0 时**答题头与顶栏同步显示剩余倒计时**，到点自动交卷；**刷新/切后台后重新打开会自动恢复考试，并按持久化的截止时间继续倒计时（不重新计时）**；交卷后**整卷判分**；客观题未作答计错，**简答题未自评不计分也不计错**（结果页列「待自评」，不含在正确率内，可在结果页逐题/逐小问内联自评）；交卷前列明未作答题数与待自评提示并可返回检查；记录切出页面次数（切标签/最小化均计入），结果页与历史中可查 |
| 组卷（混合出题） | 按**每题型数量**抽题，可用分类、难度区间（1–5）过滤；题量不足按实际数量组卷并提示；可选择练习或考试模式，可单独开关本场「题目顺序乱序」「选项乱序」「材料题小问乱序」 |
| 章节顺序练 | 选分类（章节）后按**题库原始顺序**逐题作答，不抽题不洗牌，支持练习/考试，适合系统过教材；可限制题量 |
| 材料题（综合题） | 顶部显示**共享材料**，其下多个小问混合六类题型；逐小问判分，**整题满分 = 各小问按「本场显式题型分值 > 小问自带分值（1–100）> 默认 10」累加**；可在开始弹窗开关本场**小问乱序**（整题去重键不变）；含简答小问时提交后逐个自评；整题为一个复习/错题单位 |
| 错题练习 | 从错题本抽取重新练习（可选**题型/分类/题量**，默认全部历史错题） |
| 错题+薄弱集训 | **1 次点击直接开练**：错题本成员 ∪ 薄弱题（逐题正确率 <60% 且作答 ≥2；`good/easy` 计正确，`hard/again` 计作答不计正确）。首页与错题页共用同一入口；生成过程**不写库、不新增进度键**，错题/收藏/复习状态保持不变；空池时提示口径而不打开空练习 |
| 收藏练习 | 从收藏夹抽取练习 |
| 今日复习 | **间隔重复（SRS）**：按题库每日额度排队（学习步骤 → 到期复习 → 新题），额度跨会话累计，答完按对/错安排下次复习时间；首页显示本轮实际排入题量与构成 |

**间隔重复（今日复习）**：系统采用 **FSRS-6** 算法（Anki 同源的新一代间隔重复模型）对每道题维护**稳定度**与**难度**，让到期时刻的预期保留率约为 90%：评分越好间隔拉得越长，忘记（again）则间隔骤缩并当天再到期。首页「🧠 今日复习」显示**本轮队列**（默认每日新题 20 / 到期复习 200），并**按当天已用额度递减**——同一天多次点「今日复习」不会重复灌入同一批新题；统计页「今日复习计划」显示今日已引入/已复习与剩余额度，可**按题库调整**调度设置（见下），设置随题库记录一起备份与同步。进度按题库分别保存在本地；早期版本的 SM-2 记录在首次评分时自动迁移（不继承旧 ease，一次评分后即收敛），旧的 17 维 FSRS-4.5 个性化权重因维数不兼容会自动回落官方默认（不影响复习进度）。算法公式、队列规则、每日额度推导、学习步骤状态机、个性化优化器与数据结构见 [SRS.md](SRS.md)。

**调度设置（按题库）**：在统计页「今日复习计划」的齿轮可打开设置，字段与默认值：

| 设置项 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 每日新题 | 0–999 | 20 | 0 = 不排新题 |
| 每日到期复习 | 0–9999 | 200 | 0 = 不排到期复习 |
| 目标保留率 | 0.70–0.97 | 0.90 | 到期时希望记住的比例；**越高 → 间隔越短** |
| 最大间隔（天） | 1–36500 | 36500 | 新算出的间隔上限 |
| 学习步骤（秒） | 1–4 个正整数，逗号分隔 | 60,600（即 1 分钟、10 分钟） | 新卡/重学步骤；只配 1 个时「会」直接毕业 |
| 难卡阈值 | 0–9999 | 8 | 0 = 关闭；达到阈值即显示「难卡」徽标 |
| 难卡命中后动作 | 仅徽标 / 标记 | 仅徽标 | 默认只显示徽标；选「标记」会写入持久难卡标记（不暂停卡片） |
| 间隔模糊 | 开/关 | 关 | 开启后新算出的间隔按官方区间比例抖动；同库同题同复习次数结果可复现 |
| 模糊幅度上限（天） | 0–36500 | 0 | 语义固定：**0 = 仅用官方 δ，不额外收紧；>0 = 收紧到该天数**（只能收紧，绝不放大）。合法值 `0` / `999` 均不报错 |
| 轻松日权重（周日→周六） | 7 × 0–100 | 全 100 | 到期日落在降权周几时按比例压缩间隔；0% 压到 1 天，结果不会小于 1 天 |

**复习设置弹窗的控件**：真假值开关（间隔模糊 / 标记难卡）使用复选框，难卡动作是下拉选择；窄屏（360 档）轻松日权重按 4+3 两行排列。弹窗内所有数字框、下拉与复选框热区均为 **≥44×44 CSS px**（复选框由整行 label 承担热区），可键盘操作（`Space` 切换复选框、方向键切换下拉、`Esc` 关闭并回到触发按钮）。

**所有调度参数只对之后的评分与到期生效**：保存设置不会重排已有到期时间，也不会批量改写已有学习状态；表单中的非法值（非整数、越界、空步骤等）会**就地显示红色错误提示并拒绝保存**，不再静默丢弃。**保存后立即生效**：设置变更（含其他标签改库、备份恢复、直接改库）会同步丢弃旧缓存，后续评分不会继续使用旧保留率/步骤/上限（C019）。

**判分规则**：判断题（对/错）、单选（字母）、多选（集合相等）、**不定项**（答案可能 1～多个：全对满分，少选且未选错得半分，错选/多选 0 分，且不进错题本）、填空（逐空比对，忽略大小写/空格/全角）；简答题不自动判分，练习时由用户自评。**判断题的题干答案或作答无法解析为「正确/错误」时按待判定处理（不计分、不计错、不写 SRS）**；未作答仍按错处理。**材料题**按小问递归判分并整题聚合：任一硬错→错误；无硬错但含少选→整题“半对”（得分按小问累加，结果页/答题卡/SRS 均按半对处理）；含待自评小问→整题待自评（不计分、不计错、不写 SRS）。

**作答反馈位置**：练习模式提交后，正确答案/你的答案/解析紧随题面显示，位于「下一题/上一题/收藏」等操作按钮与底部答题卡之上；解析不再被压在页面最底部。

**选项乱序**：练习与考试时，单选/多选/不定项的选项会**随机排列**，正确答案字母随之自动调整，避免背位置。该乱序只影响当次作答（题库里存储的原始顺序不变）：可在 `js/config.js` 的 `SHUFFLE_OPTIONS` 设全局默认，也可在「组卷」弹窗及「练习模式 / 考试模式」开始弹窗里对单场单独开关；判断题（固定 正确/错误）、填空、简答不参与。

**答题卡与界面固定**：做题页的「答题卡」用颜色区分状态——**未答灰、已答蓝、正确绿、错误红、待自评黄**，卡下方有对应图例，点击格子可直接跳题。顶部「首页 / 错题本 / 收藏夹 / 历史 / 统计 / 搜索」菜单栏在滚动时**固定在页面顶部**；历史页的「历史统计」卡片、搜索页的「筛选框 + 共 X / Y 题 + 用搜索结果练习」**同一行**也都固定在菜单栏下方，滚动列表时始终可见。列表/结果页向下滚动较远后，右下角出现「↑ 回到顶部」与「↓ 直达底部」两个悬浮按钮（点击平滑滚动；距顶/距底约 400px 内自动隐藏；**答题过程中一并隐藏**，避免误触遮挡作答）；点击顶部标签切换页面时也会自动回到顶部。

## 4.1 导出数据

| 入口 | 导出对象 | 说明 |
| --- | --- | --- |
| 题库管理 → 导出 | 整个题库 | 导出当前题库全部题目 |
| 错题本 → 导出错题 | 错题本 | 仅导出错题，附错误次数 |
| 收藏夹 → 导出收藏 | 收藏夹 | 导出收藏的题目 |
| 历史页 → 导出历史 | 答题历史 | 按条导出成绩记录（时间/题库/模式/题数/对错/半对/得分/正确率/用时/切出次数），仅 JSON/CSV/XLSX/TXT，供统计归档，**不可导回** |

点击后弹窗选择格式：

- **JSON**：标准备份结构，可再次导入（推荐用于迁移/备份）。
- **CSV**：Excel 可直接打开（带 UTF-8 BOM 不乱码），也可再次导入。
- **Excel (.xlsx)**：真正的 .xlsx 工作簿（原生零依赖生成），Excel/WPS 可直接打开，也可再次导入。
- **Word (.docx)**：真正的 .docx 文档，按行式规范排版，Word/WPS 可直接打开，也可再次导入。
- **Markdown**：含答案解析的题单，便于阅读/打印，也可再次导入（往返）。
- **纯文本 TXT**：等宽排版试卷（阅读用，不可导回）。

文件名形如 `物业题库A-错题本-36题-20261013-1830.xlsx`；历史记录单位为「条」，形如 `物业题库A-历史记录-12条-20261014-1015.csv`。详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。

### 4.2 分发题包（发给别人、别人一键收）

题库管理工具栏的「**导出分发题包**」把当前题库导出为带清单的 `.qbk`：

1. 在弹窗填写**版本**（默认 `1.0.0`）、作者/描述（可选）；
2. 可先点「**只读预览**」——用本机分享页打开，不联网、不上传，确认内容后再导出；
3. 点「导出题包」得到 `题库名-分发题包-v1.2.0-538题-<YYYYMMDD-HHMMSS-SSS>.qbk`（时间精确到毫秒，同一毫秒内连续导出再追加序号，不会同名覆盖），与普通 `.qbk` 相比仅多一个约 300 B 的 `manifest.json`（题包 id / 版本 / 题数 / 校验和）。

收到题包的人用「导入」选择该文件（或粘贴 `.qbk` 的 http(s) 直链，按二进制拉取，受 8MB 快照上限约束）即可：预览会显示题包名/版本/题数与**清单校验和一致/不一致**。校验不匹配只警告、不阻断。**同一个题包（同 id + 同版本）再次导入**时会先弹窗让你选：

- **跳过**：不写入；
- **并存**：合并导入，已有相同题目（contentHash 相同）自动跳过；
- **覆盖**：清空该库题目后写入。

同一题包的新版本（id 相同、版本不同）只提示版本变化，按合并去重导入。旧的、没有 manifest 的 `.qbk` 行为完全不变。

题目批注会随 `.qbk`/JSON 一起带走：导出端只在有批注的题上写 `annotation`，接收方导入后练习反馈、材料题总评和只读分享页都能看到；旧版客户端忽略该字段不影响题目、清单与 checksum 校验，也不会产生警告。

### 4.3 分享链接 / 粘贴码（离线收题，无账号无服务端）

题库管理工具栏的「**分享链接/码**」与「导出分发题包」共用同一套题包构建（`manifest.json` 一致），但不下载文件，而是生成两种投递形态：

1. 填写版本/作者/描述（与 4.2 相同），点「生成分享链接/码」；
2. 弹窗显示 **回链**（`当前页面地址#share=<码>`）与 **粘贴码**（`qfshare1:<…>`），两个都有「复制」按钮；
3. 直接把回链发进聊天窗口，或只发那串粘贴码。**同一份题包字节 → 同一个码**（确定性）；重新导出会写入新的导出时间戳，因此是另一份包、另一个码。

接收方两种收法，全部在浏览器本地完成，**不访问服务器、不需账号**：

- **打开回链**：页面启动时自动读取 `#share=`，弹出导入预览（题包名/版本/题数/`packageId`/清单校验和一致还是不一致），确认后落库；处理完会清掉地址栏 hash，刷新不会重复导入。本机还没有题库时，会按题包标题自动新建一个（取消导入则清理掉空库）。
- **粘贴码**：把整串 `qfshare1:<…>`（或完整回链）粘到「粘贴文本导入」，同样走预览/去重/容量预检。

限制与边界：

- 分享码硬上限 **8 MB**（与网络导入快照上限一致）；回链预计超过 **64 KB** 时**先弹窗确认再生成**（提示可只发分享码或改用分发题包文件），取消则不生成任何大字符串；已生成的回链超过 64 KB 时也会提示「优先发送分享码」，避免聊天软件截断。
- 分享页仍是**只读**（无 `<script>`、无网络请求）；回链只承载题包字节，不携带任何账号、评论或可写状态。
- 同一题包（同 `packageId` + 同 `version`）再次导入时，仍按 4.2 的三选一（跳过 / 并存 / 覆盖）处理。

## 5. 学习数据

- **错题本**：答错的题自动进入（不定项少选得半分的题不进）；可单独移除或清空；首页/错题本「错题重练」点击后可先选题型·分类·题量（默认全部错题）再开始。**练习/考试结果页的「错题重练」只重练本场答错的题**（与错题本写入口径一致：错且非半对；本场无错题则提示「本次没有错题」）。
- **收藏夹**：答题页点「收藏」加入；可移除或清空；支持收藏练习。
- **历史**：每次练习/考试记录得分、正确率、用时（考试另记切出次数与不定项半对题数）；可删除单条、清空，或导出为 JSON/CSV/XLSX/TXT 归档（见 4.1）。
- **统计**：**今日复习计划卡**（当前限额、今日已引入/已复习、剩余额度、本轮队列构成、调整入口）、FSRS 复习调度卡（已学/跟踪/新题数 + 未来 7 天每日到期柱状分布）、近 12 周学习热力日历（按日答题量分级）、**FSRS 个性化参数**卡（见 5.1）、总览（测试次数/答题数/平均正确率）、各题型掌握度、学习建议。统计页的复习预测与诊断结果按「题库 + 题目修订号 + 评分日志修订号」缓存：数据未变时重复打开不再全量扫描（P-6），评分/导入/切库后自动失效。
- **本题历史与难卡**：练习提交后，反馈下方显示**该题评分历史**（评分次数、又忘/困难/良好/简单分布、最近一次时间）；累计遗忘 ≥8 次的题在答题页标记「难卡」，建议拆分或重学。
- **未作答统计与防误点**：答题头实时显示「○ 未答 N」，答题卡摘要显示「已答 X / N · 未答 Y」；「交卷 / 结束练习」在独立末栏（桌面有分隔线、窄屏整行独占），与「下一题」拉开距离；练习中途结束会二次确认并列出已答/未答数量；考试结果页单独列出未作答（客观题注明已计为错）。**判断题的题干答案或作答无法解析为「正确/错误」时按「待判定」处理**：不计错题本、不计入正确率统计；未作答仍按错处理（C019）。
- **交卷后自评**：结果页的逐题回顾中，待自评的简答题（含材料题的简答小问）直接显示「我答对了 / 我答错了」；点击后立即重算本场得分、正确率、题型分布并回写历史记录，同时按与练习相同的口径写入 SRS/错题本（材料题仍以整题为复习单位，全部小问判定后才记一次调度）。
- **搜索**：按关键词检索**题干、选项、答案、填空、参考答案、解析、材料正文与子问题、分类、标签**（命中高亮），可按题型、分类、**标签**组合筛选，从结果直接开始练习；筛选框、结果计数（共 X / Y 题）与「用搜索结果练习」按钮**排在同一行并固定在页面顶部**；结果与错题本、收藏夹一样按每页 20 条**分页**浏览（不再有 200 条上限）。

### 5.1 FSRS 个性化参数

系统从本版起记录每道题的**评分日志**（又忘了/困难/良好/简单及时间，本地保存，上限 2 万条）。统计页的「FSRS 个性化参数」卡显示训练样本进度：

- **学习步骤**：新卡首次评分对齐 Anki 默认 1m/10m——「又忘了/困难」→ 1 分钟后到期，「良好」→ 10 分钟后到期，「简单」→ 直接毕业；走完步骤后按 FSRS 长期间隔排期。已毕业卡遗忘后进入同样的重学步骤，毕业后续接原有长期间隔。learning/relearning 期间每次评分也累计 `reps`，S/D 沿用。
- **按题库权重（preset）**：卡片顶部可切换「全局（跨题库）/具体题库」作用域。**训练样本与权重同作用域**：按题库训练只用该题库的评分日志，全局训练用全部日志（升级前的旧日志无题库标记，只参与全局训练）；权重保存后，题库有自己的 preset 时优先使用，否则回退全局，再回退官方默认；各作用域可单独恢复默认（官方推荐难度差异大的题库分开训练）。
- **冷启动**：样本不足 **100 个相邻评分对**（或「又忘了」不足 3 次、评分档位不足 3 种）时，使用官方 **21 个**默认权重，按钮禁用。
- **训练参数**：达标后可一键训练。优化器用伯努利最大似然 + 梯度下降寻找更贴合你遗忘规律的权重；仅当 logloss 比默认权重改善 **≥0.2%**、且权重在合理区间时才采纳，否则保留默认（不会越训越差）。http(s) 环境训练在后台 **Web Worker** 线程执行（训练期间可正常操作，不卡顿）；file:// 双击打开或后台线程异常时自动回退当前页计算，结果一致。
- 权重按作用域生效（全局或指定题库 preset），训练后只影响后续评分的间隔演进，已有复习计划不重算；可随时在对应作用域「恢复官方默认」。
- 历史评分不回填：升级前只有最新状态、没有日志，需要从升级后继续练习积累样本。

## 6. 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `?` | 打开快捷键帮助（也可点顶栏「?」按钮） |
| `1` – `8` | 答题页选择对应序号的选项 |
| `Enter` | 提交当前题 / 未作答时进入下一题 / 末题结束 |
| `←` / `→` | 上一题 / 下一题 |
| `Esc` | 关闭弹窗 |

> 在有输入框/文本域/下拉框获得焦点时，快捷键自动让位（不干扰输入）。

**键盘可达与焦点**
- 首页菜单项、选项、答题卡格等可交互项均可用 `Tab` 聚焦；`Enter` / `Space` 激活（选项会按当前题型选中，再按 `Enter` 提交）。
- 任意弹窗打开后，焦点自动进入弹窗内第一个可聚焦控件；`Tab` / `Shift+Tab` 只在弹窗内循环，不会跑到背后的页面。
- `Esc` 关闭弹窗，关闭后焦点回到打开它的按钮（如「练习模式」「导入」），继续键盘操作不会丢失位置。

**移动端与减少动效**
- 360px 起即可正常使用：页面不出现横向滚动，关键按钮与答题卡格的点击区域不小于 44×44 CSS px（触屏可点）。
- 弹窗在窄屏下不超出视口，内容过长时弹窗内部可滚动，不会遮挡底部操作。
- 系统开启「减少动效」（`prefers-reduced-motion`）时，界面动画与过渡会被关闭或压到几乎瞬时；应用无需额外设置。

## 10. 已知限制

- `.xlsx` / `.docx` 解析依赖浏览器 `DecompressionStream`；过老浏览器可能不支持。
- 存储：默认 IndexedDB（上限由浏览器按站点分配）；**IDB 不可用时回落 LocalStorage（通常 5–10MB）**，超大题库仍建议分库、或启用自建后端（§1.1）。
  - 首页「本地存储」卡显示**已用 / 上限**：IndexedDB 下上限由浏览器管理，拿不到配额时只显示已用、不画百分比条（不会把 5MB 的 LocalStorage 配额当成上限而误报满格）。
  - 回落时启动会**明确提示**「IndexedDB 不可用/读取失败，已切换到兼容模式」并给出重试方式，不会出现「库是空的却没有任何说明」；原标记会保留，退出隐私模式或恢复 IDB 后刷新即可自动重试升级。若回落期间新建/导入了数据，会永久切到兼容模式，避免下次升级时丢失这些数据。此时请尽快在「备份与恢复」导出备份。
- **容量数字同口径**：首页「本地存储」卡的已用字节、导入前容量预检、备份体积提示使用同一套字节口径（R-07），同一份数据在三处显示一致。
- **启动水合（已知限制）**：IDB 模式启动时会把题库数据一次性载入内存（题目/复习状态/日志），启动内存与题目量近似线性。分层懒加载经实测会静默丢题/丢复习状态（R-10 判定 no-go），因此未采用；超大题库建议分库。
- 应用支持 **PWA**：通过 http(s) 访问（如 GitHub Pages）时可用浏览器「安装到主屏幕/桌面」，Service Worker 缓存后可离线打开；**首次访问注册 SW 后需刷新一次才由 SW 接管当前页**（Service Worker 正常语义，第二次及以后加载直接命中缓存）；`file://` 双击场景不启用离线缓存。检测到新版本时会提示「刷新页面即可更新」（不会在答题中自动刷新）。
- **批注是纯本地字段**：自建后端（`DATA_BACKEND=api`）的服务端 schema 与接口不含 `annotation`，编辑器会禁用批注输入；如需跨设备共享批注，请用 JSON/`.qbk` 备份导入，或等待后续后端 schema 扩展。
