# 使用指南（user-guide）

> 面向使用者的操作说明。功能行为变更时须同步更新本文档。

## 1. 打开与启动

- **直接打开**：双击 `index.html`（纯前端，无需安装）。
- **本地服务（推荐）**：`node scripts/serve.mjs` → 浏览器访问 `http://localhost:8777`。

首次进入是空系统，需要导入或新建题库。

## 2. 题库管理

顶部下拉框可切换当前题库；点击「管理题库」进入题库列表。

| 操作 | 说明 |
| --- | --- |
| 新建题库 | 输入名称（可选描述/分类）创建 |
| 重命名 | 修改题库名称 |
| 删除题库 | **级联删除**该库下所有题目、错题、收藏、历史 |
| 切换当前题库 | 顶部下拉选择；题目与学习数据按库隔离 |
| 导入示例题库 | 一键载入内置 18 题样例（判断/单选/多选/不定项/填空/简答六题型，其中不定项 3 题）；材料题样例见 `samples/示例-材料题.json/.md/.docx/.csv/.xlsx`（JSON/Markdown/Word/CSV/Excel 均可导入，排版见导入格式说明 §3.1/§6.1；嵌套编辑器后续提供） |

## 3. 导入题库

点击「导入」选择文件，支持：

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| 题库包 | `.qbk` | stored ZIP（bank.json + `assets/*`），**唯一携带图片**的导入格式，见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md) §9 |
| JSON | `.json` | 标准数组 / 本系统导出格式 / 中文扁平 / 中文嵌套（自动嗅探） |
| CSV / TSV | `.csv` `.tsv` `.txt` | 表头映射（题目/题型/选项A–D/答案/解析…，中英兼容） |
| Markdown | `.md` `.markdown` | 按 `## 1. 题干 / - **A.** 选项 / **答案：X**` 排版；与本系统 md 导出互通，可往返 |
| Excel | `.xlsx` | 读取**全部工作表**（首行表头，空表跳过，多表合并），按表头映射，原生解析 |
| Word | `.docx` | 按「1. 题干 / A. 选项 / 答案：X」排版切题；**支持内嵌图片**（DrawingML/VML 自动提取到 IndexedDB，见 3.3） |

导入流程：**选择文件 → 预览（题量/各题型/警告/重复）→ 选目标题库 → 合并或覆盖 → 落库**。

- **材料题（综合题）导入**：JSON/.qbk 直接支持；Markdown/Word 用行式材料块（`[材料题]` 引导行 + `材料：` + `(1). [题型]` 小问，见导入格式说明 §6.1/§5.2）；CSV/Excel 用「材料/小问」两列多行块（表头含材料题时导出自动追加两列，见 §3.1）。各格式导出 → 再导入均可无损往返。

- **合并**：保留库内已有题目，仅新增不重复的题。
- **覆盖**：清空目标题库后写入（谨慎使用）。
- 去重键为「题型 + 规范化题干 + 选项 + 正确答案」：题干相同但选项或答案不同的题会分别保留；分类/难度/标签差异不视为不同题。重复题自动跳过。
- **粘贴文本导入**：首页「粘贴文本导入」直接粘贴 JSON（标准结构/数组）或行式题目（`1. 题干 / A. 选项 / 答案：X / 解析：… / 分类：… / 难度：… / 标签：…`），解析规则与 Markdown 文件一致，无需先存成文件。
- **拖拽导入**：把支持的文件直接拖到窗口任意位置即可（答题中禁用）；会出现虚线提示框，松开后进入同样的预览流程。
- **网络地址导入**：在 http(s) 环境（GitHub Pages / 本地服务；`file://` 双击时禁用）点「网络地址导入」，粘贴 json/csv/md/xlsx/docx 的直链，拉取上限 8MB、15 秒超时。远端文件以**快照**保存到本地，可离线、可备份；题库卡片显示 🌐 来源，可用「↻ 刷新网络来源」重新拉取，内容指纹（checksum）未变会提示无更新，有变化则去重合并。服务器必须允许跨域（CORS），否则请另存为文件后拖拽导入；需要登录的私有地址不支持，请走未来的 REST 后端。
- 题库卡片显示**来源徽章**：📁 本地创建 / 📄 文件 / 📋 粘贴 / 🖱️ 拖拽 / 🌐 网络。
- 详细格式规范见 [IMPORT-FORMAT.md](IMPORT-FORMAT.md)。

导出：题库列表点击「导出」（或错题本「导出错题」、收藏夹「导出收藏」），弹窗选择 JSON / CSV / Excel(.xlsx) / Word(.docx) / Markdown / TXT 六种格式；除 TXT 外均可再次导入往返，详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。

### 3.1 题目管理（新增 / 编辑 / 删除）

首页「题目管理（新增/编辑/删除）」打开题库内管理器：

- 顶部可按**题型、难度、标签、题干关键词**组合筛选（标签候选项来自当前题库），每页 10 题分页浏览；行内显示题型、难度（★）、分类/标签与答案预览。
- **＋ 新增题目**：选择题型后填写题干、选项（勾选左侧即正确项，可增删选项、字母自动重排）或填空空位/简答参考答案，并设置解析、分类、难度（1–5）、标签。保存前会校验题干、选项数与正确答案。
- **编辑**：修改后保存；编辑难度/标签/分类不影响去重键（错题、收藏不会因此丢失关联）；修改题干/选项/答案会生成新的内容键（等同新题，旧作答记录不迁移）。
- **删除**：单题删除需确认；勾选多题后可「删除所选项」批量删除。操作不可恢复。

### 3.2 题干中的上标 / 下标（轻量公式）

题干、选项、解析、参考答案均支持纯文本上下标记号（各导入/导出格式原样保留，无需转义）：

| 写法 | 显示 | 示例 |
| --- | --- | --- |
| `x^{2}` | x<sup>2</sup> | `E=mc^{2}`、`10^{3}` |
| `a_{n}` | a<sub>n</sub> | `H_{2}O`、`a_{n+1}` |

- 花括号必须成对出现；普通文本里的 `^`、`_`（如 `snake_case`、`2^3`）不受影响、原样显示。
- 希腊字母等 Unicode 符号（α、β、π、℃、≥）直接输入即可，无需特殊语法。
- 复杂公式（分式、根号、矩阵）不在支持范围内，按零依赖定位不引入公式库。

### 3.3 图片题（IndexedDB 本地存图）

题干、选项、解析、参考答案均可插图，图片二进制不占用 localStorage 配额：

- 在编辑器先点击目标文本框（题干/选项/解析）定位光标，点「**📷 插入图片**」选本地图片，保存题目即可；标记语法为 `![](asset:图片id)`，随文本保存。
- JPEG 超过 1600px 长边时自动按 0.82 质量压缩；PNG/GIF/WebP/SVG 原样保存以保留透明与动画。
- 图片存在浏览器 **IndexedDB**（按内容哈希去重，同图不重复占空间）；**file:// 双击打开时 IndexedDB 在部分浏览器被禁用**，图片题请通过 `node scripts/serve.mjs` 或 GitHub Pages 使用。
- **DOCX 导入支持内嵌图片**：Word 文档中题干/选项/解析段落里的图片（DrawingML `a:blip`，兼容旧版 VML）会随切题自动提取——图片字节写入 IndexedDB，题面相应位置插入占位标记；重复导入同图按内容哈希去重；文档引用了但包内缺失的图片会在预览中警告并跳过，不影响切题。图片归属按段落就近挂接（独立图片段落续接到题干），复杂文本框/嵌套表格排版可能错位，导入后请预览核对。
- 带图题库的跨设备迁移必须导出「**题库包 .qbk**」（导出端只有 .qbk 携带图片字节；JSON/CSV/XLSX/DOCX/MD 导出仅保留占位文本，但 **DOCX 文件导入时可以带图**）；.qbk 可再次导入并自动回写图片，缺图会在预览警告。**材料题**（共享材料正文与各小问）中的图片同样随 .qbk/.qfbk 携带（2026-10-19 修复：此前引用集只扫题干/选项/解析，漏扫材料正文与小问）。
- 「备份与恢复」在存在图片时自动导出 `.qfbk` 包（数据 + 全部图片），无图时仍是单个 JSON；备份管理中可「清理未引用图片」回收空间（删题后残留的图）。
- 图片占位在做题、解析回顾处自动加载；列表/搜索以 `[图]` 紧凑显示。

## 4. 刷题模式

| 模式 | 说明 |
| --- | --- |
| 练习模式 | 点击后弹窗按题型设置**抽取数量（0=不选该题型）与每题分值**，并可选分类、单独开关本场「选项乱序」与「显示计时（正计时，默认关闭）」；每题作答后即时判分；简答题作答后可**自评**对/错；分值仅本场生效，不写回题库 |
| 考试模式 | 点击后弹窗同样按题型设置**抽取数量与每题分值**，并可设**考试时长（分钟，默认 30，0=不限时）**、开关本场「选项乱序」；时长>0 时倒计时，到点自动交卷；交卷后**整卷判分**；客观题未作答计错，**简答题未自评不计分也不计错**（结果页列「待自评」，不含在正确率内；需要评分请在练习模式作答后自评）；交卷前列明未作答题数与待自评提示并可返回检查；记录切出页面次数（切标签/最小化均计入），结果页与历史中可查 |
| 组卷（混合出题） | 按**每题型数量**抽题，可用分类、难度区间（1–5）过滤；题量不足按实际数量组卷并提示；可选择练习或考试模式，可单独开关本场「题目顺序乱序」与「选项乱序」 |
| 章节顺序练 | 选分类（章节）后按**题库原始顺序**逐题作答，不抽题不洗牌，支持练习/考试，适合系统过教材；可限制题量 |
| 材料题（综合题） | 顶部显示**共享材料**，其下多个小问混合六类题型；逐小问判分，**整题满分 = 各小问按「小问题型分值」累加**（题型分值未单设时默认 10 分/小问），含简答小问时提交后逐个自评；整题为一个复习/错题单位 |
| 错题练习 | 从错题本抽取重新练习（可选**题型/分类/题量**，默认全部历史错题） |
| 收藏练习 | 从收藏夹抽取练习 |
| 今日复习 | **间隔重复（SRS）**：自动汇总今日到期与未学过的题，答完按对/错安排下次复习时间 |

**间隔重复（今日复习）**：系统采用 **FSRS-6** 算法（Anki 同源的新一代间隔重复模型）对每道题维护**稳定度**与**难度**，让到期时刻的预期保留率约为 90%：评分越好间隔拉得越长，忘记（again）则间隔骤缩并当天再到期。首页「🧠 今日复习」显示今日到期题数（带红点），进度按题库分别保存在本地；早期版本的 SM-2 记录在首次评分时自动迁移（不继承旧 ease，一次评分后即收敛），旧的 17 维 FSRS-4.5 个性化权重因维数不兼容会自动回落官方默认（不影响复习进度）。算法公式、学习步骤状态机、个性化优化器与数据结构见 [SRS.md](SRS.md)。

**判分规则**：判断题（对/错）、单选（字母）、多选（集合相等）、**不定项**（答案可能 1～多个：全对满分，少选且未选错得半分，错选/多选 0 分，且不进错题本）、填空（逐空比对，忽略大小写/空格/全角）；简答题不自动判分，练习时由用户自评。

**选项乱序**：练习与考试时，单选/多选/不定项的选项会**随机排列**，正确答案字母随之自动调整，避免背位置。该乱序只影响当次作答（题库里存储的原始顺序不变）：可在 `js/config.js` 的 `SHUFFLE_OPTIONS` 设全局默认，也可在「组卷」弹窗及「练习模式 / 考试模式」开始弹窗里对单场单独开关；判断题（固定 正确/错误）、填空、简答不参与。

**答题卡与界面固定**：做题页的「答题卡」用颜色区分状态——**未答灰、已答蓝、正确绿、错误红、待自评黄**，卡下方有对应图例，点击格子可直接跳题。顶部「首页 / 错题本 / 收藏夹 / 历史 / 统计 / 搜索」菜单栏在滚动时**固定在页面顶部**；历史页的「历史统计」卡片、搜索页的「筛选框 + 共 X / Y 题 + 用搜索结果练习」**同一行**也都固定在菜单栏下方，滚动列表时始终可见。列表/结果页向下滚动较远后，右下角出现「↑ 回到顶部」与「↓ 直达底部」两个悬浮按钮（点击平滑滚动；距顶/距底约 400px 内自动隐藏；**答题过程中一并隐藏**，避免误触遮挡作答）；点击顶部标签切换页面时也会自动回到顶部。

## 4.1 导出数据

| 入口 | 导出对象 | 说明 |
| --- | --- | --- |
| 题库管理 → 导出 | 整个题库 | 导出当前题库全部题目 |
| 错题本 → 导出错题 | 错题本 | 仅导出错题，附错误次数 |
| 收藏夹 → 导出收藏 | 收藏夹 | 导出收藏的题目 |
| 历史页 → 导出历史 | 答题历史 | 按条导出成绩记录（时间/题库/模式/题数/对错/半对/得分/正确率/用时/切出次数），仅 JSON/CSV/XLSX/TXT，供统计归档，**不可导回** |

点击后弹窗选择格式：

- **JSON**：标准备份结构，可再次导入（推荐用于迁移/备份）。
- **CSV**：Excel 可直接打开（带 UTF-8 BOM 不乱码），也可再次导入。
- **Excel (.xlsx)**：真正的 .xlsx 工作簿（原生零依赖生成），Excel/WPS 可直接打开，也可再次导入。
- **Word (.docx)**：真正的 .docx 文档，按行式规范排版，Word/WPS 可直接打开，也可再次导入。
- **Markdown**：含答案解析的题单，便于阅读/打印，也可再次导入（往返）。
- **纯文本 TXT**：等宽排版试卷（阅读用，不可导回）。

文件名形如 `物业题库A-错题本-36题-20261013-1830.xlsx`；历史记录单位为「条」，形如 `物业题库A-历史记录-12条-20261014-1015.csv`。详见 [EXPORT-FORMAT.md](EXPORT-FORMAT.md)。

## 5. 学习数据

- **错题本**：答错的题自动进入（不定项少选得半分的题不进）；可单独移除或清空；首页/错题本「错题重练」点击后可先选题型·分类·题量（默认全部错题）再开始。**练习/考试结果页的「错题重练」只重练本场答错的题**（与错题本写入口径一致：错且非半对；本场无错题则提示「本次没有错题」）。
- **收藏夹**：答题页点「收藏」加入；可移除或清空；支持收藏练习。
- **历史**：每次练习/考试记录得分、正确率、用时（考试另记切出次数与不定项半对题数）；可删除单条、清空，或导出为 JSON/CSV/XLSX/TXT 归档（见 4.1）。
- **统计**：FSRS 复习调度卡（已学/跟踪/新题数 + 未来 7 天每日到期柱状分布）、近 12 周学习热力日历（按日答题量分级）、**FSRS 个性化参数**卡（见 5.1）、总览（测试次数/答题数/平均正确率）、各题型掌握度、学习建议。
- **搜索**：按关键词检索题干/解析/分类/标签（命中高亮），可按题型、分类、**标签**组合筛选，从结果直接开始练习；筛选框、结果计数（共 X / Y 题）与「用搜索结果练习」按钮**排在同一行并固定在页面顶部**；结果与错题本、收藏夹一样按每页 20 条**分页**浏览（不再有 200 条上限）。

### 5.1 FSRS 个性化参数

系统从本版起记录每道题的**评分日志**（又忘了/困难/良好/简单及时间，本地保存，上限 2 万条）。统计页的「FSRS 个性化参数」卡显示训练样本进度：

- **学习步骤**：新卡首次评「又忘了/困难」进入 1 分钟/10 分钟的当日学习步骤（good 走完即毕业，easy 直接毕业）；已毕业卡遗忘后进入同样的重学步骤，毕业后续接原有长期间隔。
- **按题库权重（preset）**：卡片顶部可切换「全局（跨题库）/具体题库」作用域。**训练样本与权重同作用域**：按题库训练只用该题库的评分日志，全局训练用全部日志（升级前的旧日志无题库标记，只参与全局训练）；权重保存后，题库有自己的 preset 时优先使用，否则回退全局，再回退官方默认；各作用域可单独恢复默认（官方推荐难度差异大的题库分开训练）。
- **冷启动**：样本不足 **100 个相邻评分对**（或「又忘了」不足 3 次、评分档位不足 3 种）时，使用官方 17 个默认权重，按钮禁用。
- **训练参数**：达标后可一键训练。优化器用伯努利最大似然 + 梯度下降寻找更贴合你遗忘规律的权重；仅当 logloss 比默认权重改善 **≥0.2%**、且权重在合理区间时才采纳，否则保留默认（不会越训越差）。http(s) 环境训练在后台 **Web Worker** 线程执行（训练期间可正常操作，不卡顿）；file:// 双击打开或后台线程异常时自动回退当前页计算，结果一致。
- 权重按作用域生效（全局或指定题库 preset），训练后只影响后续评分的间隔演进，已有复习计划不重算；可随时在对应作用域「恢复官方默认」。
- 历史评分不回填：升级前只有最新状态、没有日志，需要从升级后继续练习积累样本。

## 6. 键盘快捷键

| `?` | 打开快捷键帮助（也可点顶栏「?」按钮） |

## 7. 进度恢复

练习/考试过程中每答一题都会自动保存进度。刷新或重开页面后，会提示是否**继续上次未完成的答题**。

## 8. 外观

右上角按钮在**浅色 / 深色**主题间切换，偏好会记住。

弹窗内的下拉框、题量输入框等表单控件与题目编辑器使用统一外观；各类次要提示文字（如「共 X / Y 题」「正确答案：…」「不定项：少选得半分」等）统一为小号弱化样式；底部操作提示条（如「已导入 N 题」）**居中显示**，不会遮挡右下角的「↑ 回到顶部 / ↓ 直达底部」悬浮按钮。

## 9. 数据存放

数据保存在浏览器本地（LocalStorage，前缀 `qb:`）。首页「本地存储」卡片实时显示占用量与 5MB 配额进度：≥70% 变橙提示适时备份，≥85% 变红提示尽快导出。清理浏览器数据会清空题库与学习记录，请及时用「导出」备份。

### 9.0 打印 / 另存 PDF

答题列表、题目、成绩页支持浏览器直接打印（Ctrl/Cmd+P）：打印样式会自动隐藏顶栏、标签栏、按钮与弹窗，只保留主体内容，可用于纸质练习或存档。

### 9.1 全量备份与恢复（跨设备迁移）

首页「备份与恢复」可把**全部数据**（题库、题目、错题、收藏、SRS 复习计划、历史、偏好）打包成一个 `qforge-backup-日期.json`：

- **下载全量备份**：得到单文件，建议定期保存；换设备/换浏览器时用它迁移。无图为 `.json`，含图片自动打包为 `.qfbk`（ZIP）。**WebDAV 密码不写入备份**（地址/账号保留，恢复后重新填密码），备份文件可安全分享。
- **从备份恢复**：选择备份文件（.json/.qfbk 自动识别），可选「覆盖恢复」（清空现有数据与图片后写入，推荐）或「合并恢复」（同名键覆盖、保留其余数据与图片）。恢复后刷新页面。
- **☁ WebDAV 云备份**：配置 WebDAV 目录（坚果云/Nextcloud/群晖等）后一键 PUT 上传全量备份、GET 拉取并走同一恢复确认；固定对象名 `qforge-backup-latest.bin`，账号密码仅存本机 LocalStorage，**上传的备份包已脱敏密码**（换机恢复后需重填）。**CORS 限制**：浏览器要求 WebDAV 服务允许本站跨域，坚果云等公共服务默认可能被拦截（报错属浏览器/服务端策略），自建服务通常可配置。
- 弹窗显示本地存储占用，超过约 4MB 会提示尽快备份、分库；图片在 IndexedDB 不占用该配额。

> WebDAV 是手动触发的异步备份，不是实时多端同步；真正的账号化实时同步走预留的 `DATA_BACKEND=api` 后端契约（见 [DATABASE.md](DATABASE.md) 与 [API-CONTRACT.md](API-CONTRACT.md)）。

## 10. 已知限制

- `.xlsx` / `.docx` 解析依赖浏览器 `DecompressionStream`；过老浏览器可能不支持。
- LocalStorage 容量有限（通常 5–10MB），超大题库建议分库或迁往后端。
- 应用支持 **PWA**：通过 http(s) 访问（如 GitHub Pages）时可用浏览器「安装到主屏幕/桌面」，Service Worker 缓存后可离线打开；`file://` 双击场景不启用离线缓存。检测到新版本时会提示「刷新页面即可更新」（不会在答题中自动刷新）。
