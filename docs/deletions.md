# 删除记录（DELETIONS）

> **这份文件是什么**：每一次**结构性删除**（目录、公共 API、兼容层、整批文档、发行产物）的一行账。
> 判据：`scripts/check-deletions.mjs` —— 每条记录六个字段齐全、日期不晚于今天，
> 且**记的路径不得还在版本库里**（否则是"假删除"）。
>
> **登记时机**：和删除在同一个提交里。事后补的记录没人能验证。
> **为什么要有**：这个项目的删除集中在"兼容层退场"与"文档搬家"两类上——两类都会留死链或死代码，
> 而账本逼人写最后两栏：**影响哪些引用**、**跑过哪条命令确认**。

## 模板

```text
## YYYY-MM-DD · 一句话标题
- 删除：`<仓库相对路径>`、`<仓库相对路径>`
- 日期：YYYY-MM-DD
- 批准：<人/角色>
- 为什么：<说清"为什么是现在"与"不删会怎样">
- 影响：<哪些引用已改；哪条判据的假设被打破；无影响也写"无">
- 验证：<删除后跑过哪条命令，结论是什么>
```
